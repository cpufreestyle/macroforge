    Macroforge 编辑器

    从左侧选择一个宏来编辑，或新建一个。每个宏就是一个 JSON 文件，存放在 ~/.hammerspoon/macroforge/macros/。

    触发热键、键入字符串、应用启动、窗口聚焦和定时器都可以驱动动作序列： 打开应用、操作窗口、输入文字、运行脚本、调用其他宏。

    按从上到下的顺序执行。↑ ↓ 调整顺序，⎘ 复制一步，✕ 删除一步。

    删除会移除该宏的 JSON 文件，且无法撤销。
